方法特色 · 合规性

对齐监管与建模规范

规则库以 FDA 2022 PopPK 指南、EMA 建模建议及 NONMEM 最佳实践为基石，内置 mAb 专属约束（首剂量 MABEL、TMDD 探测、ADA 影响、暴露-效应分析）。每一条规则可溯源到具体指南条款或专家共识——建模过程可审计、可追溯，而非黑箱生成。

·

方法特色 · 拟人性

贴近资深定量药理专家

规则库把「资深专家脑中的默认结构与初值」显式化为可复用文本，使 Agent 的第一稿即接近专家水平；两阶段铁律（结构 / 协变量阶段分离）与 FDA 评估标准（ACCEPT / REVISE）复刻了专家的工作流与判断逻辑，而非盲目搜索。

与现有工具的本质区别

既有工具要么「模板填空」缺乏领域约束，要么「黑箱搜索」不可解释。
我们的方法让 LLM 在受约束的专家框架内自主决策——
既自动化，又合规、可解释、可信赖。

智能初值 · 热启动继承

收敛值即最佳起点

新模型初值继承上一轮 final estimate：同义参数直接复制，新增参数取邻近值扰动，OMEGA/SIGMA 给合理初值——绝不回退到 0.1/1/10 这类盲目重置，这是建模失败最常见也最隐蔽的来源。

LLM Agent · 两阶段铁律

Phase 1 · 结构模型

仅允许调整房室数 / 误差 / IIV；禁止协变量；必须最小化 + 协方差步成功。

Phase 2 · 协变量

禁止改结构；逐一测试协变量；以 ΔOFV 阈值决定保留或剔除。

两阶段分离，复刻专家工作流，保证建模过程可追溯、可复现。

现有工具 · 瓶颈清单

不看是什么药

mAb 的 CL/V 受靶点与分子格式驱动，工具却只凭本项目数据猜。

规则库静态

人工编写、版本固定，新机制出现时滞后，无法量化相似靶点区间。

搜索成本高

GA 盲目搜索需数百次 NONMEM；若知典型区间，空间可缩十倍。

知识未结构化

跨项目经验未形成「靶点 → 参数」的可计算先验，换项目从头再来。

为什么是深度学习

高维非线性

靶点×分子×方案的交互远超人工规则可枚举，网络自动学交互。

迁移已有药物

同靶点同格式的归档参数即「近邻先验」，冷启动不再盲目。

主动缩小搜索

先验区间把 GA 搜索空间降至十分之一，NONMEM 调用降一数量级。

预测形式为参数对数正态分布区间（如 log CL ~ N(μ, σ)），直接作为 GA 搜索边界与初值范围。
